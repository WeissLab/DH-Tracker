DH-Tracker

  • www.WeissLab.ca
  • Movie: scroll to zoom, drag to pan, click a bead to select its track.
  • ROIs: draw one to select the tracks inside. Hold Shift to add, Alt to remove.
  • ☆ in the selection pill stars tracks so they stay handy.
  • 3D / plots: click a track to select it; double-click an axis to set its range.
  • ☰ opens the controls: display, filters, coordinates, tracking, export.
  • New analysis analyses a calibration z-stack and one or more movies.
  • F1 (or ☰ › Help) opens the README. Also: explorer README · video guide.
